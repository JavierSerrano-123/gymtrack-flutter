# GymTrack Flutter

Aplicación de gestión de gimnasios desarrollada con Flutter y Firebase.

## Descripción

GymTrack es una aplicación enfocada en la administración de clientes, membresías y pagos para gimnasios. Permite registrar clientes, controlar vencimientos y llevar historial de pagos desde una interfaz simple y moderna.

## Tecnologías utilizadas

* Flutter
* Firebase
* Cloud Firestore
* Firebase Authentication
* Google Sign In
* Material Design

## Funcionalidades principales

* Registro de clientes
* Control de membresías
* Historial de pagos
* Dashboard administrativo
* Gestión de clientes vencidos
* Login con Google
* Persistencia de datos en la nube
* Aplicación multiplataforma (Android/Web)

## Instalación

### 1. Clonar repositorio

```bash
git clone https://github.com/JavierSerrano-123/gymtrack-flutter.git
```

### 2. Entrar al proyecto

```bash
cd gymtrack-flutter
```

### 3. Instalar dependencias

```bash
flutter pub get
```

### 4. Ejecutar proyecto

```bash
flutter run
```
